Traversal Rules

Pre-order (Root → Left → Right)
Visit the current node first, then move to the left subtree, then the right subtree.

In-order (Left → Root → Right)
Visit the left subtree first, then the current node, then the right subtree.

Post-order (Left → Right → Root)
Visit the left subtree first, then the right subtree, and visit the current node at the end.
